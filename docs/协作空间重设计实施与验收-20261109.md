# 协作空间重设计实施与验收

对应用户确认的效果图：群聊右栏以任务与成果为默认入口，资料按文件夹管理，记忆、会议继续沿用真实对象；新增本群资源管理。左侧仍管理全局连接、Vault 与技能。

## 产品行为

- **任务**：按任务和其 Todo 展示负责人、进展、受阻原因与直接可打开的成果。保留待核对、需修改、需重新核对；Todo 全部结束不等于任务已交付。已核对的产物改版后，在当前任务中重新显示，历史核对记录保留。已完成区域默认收起。
- **资料**：统一文件夹体系；类型筛选是次级入口。文档打开最新可编辑正文，附件打开下载和版本记录，外链直接打开网页。聊天或核对的历史引用仍读取固定版本。移动、改名、删除、回收站、恢复继续有效。
- **资源**：列出本群可使用的连接器账号、技能和默认资料目录。默认开放；群开关真实影响工具调用，而非只改变显示。全局关闭的范围仍有效。默认账号供未明确选账号的操作使用，其余账号仍可指定使用。聊天中新建文档和上传附件采用群默认目录，文件夹内操作采用当前目录。
- **全局与本群分开**：首次登录、新增服务、凭证仍在全局入口；本群只存资源选择，不复制密码或修改全局资源版本。用户随时可后置调整。
- **Agent 更新**：新增 `channel_resources`；当前产品上下文会返回新约定及工具变化。已缓存旧目录的 Agent 可通过已认证 `HUB_SHARED_TOOL_V1` 调用，不要求重登录或重建成员。

## 实现边界

群设置存于原 channel 的 `resourcePreferences`，带独立版本与并发校验，不新增第二套工作区或调度系统。连接器目录、实际服务调用、托管任务领取与结果回传、旧 GitHub 入口、公众号以及技能读取/任务绑定均核对群设置。调用途中关闭资源时，不交付结果、不自动重做外部写入；不能据此声称外部操作被撤销。其他群不因该群开关丢失正在处理的连接版本。

任务概览使用缩短响应，完整要求、成果和历史仍从原详情读取；裁剪不改变真正的核对有效性。初次显示可利用已收到的快照，刷新失败保留已显示内容。资源页复用安全元数据缓存，不缓存凭证明文或授权链接。

## 验证

- 单元与协议：默认开放、显式范围优先、群隔离、多账号默认选择、旧工具兼容、资源并发版本、凭证不进入群元数据、远程调用中途关闭、托管任务领取及结果回传、技能内容版本不变。
- 任务概览：裁剪不丢核对状态；原件改版的已完成任务回到当前任务，历史提交与核对不改写。
- 浏览器：默认任务、直接打开最新版及历史版并存、文件夹内三类资料分别执行不同动作、资源设置保存与刷新、多账号及另一群隔离、默认目录真实落位、桌面与窄窗口。
- 既有流程回归：文件夹/回收站、记忆新建修改停用、会议关联 Todo、真实成果提交与核对、任务归组与移动。
