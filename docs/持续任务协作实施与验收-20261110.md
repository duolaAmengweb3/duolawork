## 实现

- `cloud/collaboration/task-intents.mjs`：动态意图、关联/改归属/修订/合并的事务操作；每条原话保留来源；来源关联不凭关键词猜测。
- `task-deliverables.mjs`：沿用实际提交、核对和依赖，普通补充不作废所有节点；新持续任务的子项能看到根的最新原话但不把每个根补充自动视为子项失效。
- `conversation.mjs` / `inbox.mjs`：普通消息与任务关联、成员反馈自动回流、最新原话/意图到原生上下文、持久接续与来源复核分别处理。
- `shared/collaboration-guidance.mjs`：现有原 Agent 领取和读群时获得新版本协议；旧缓存工具目录兼容 action/body，不要求重登录或新建身份。
- `TaskIntent.jsx` / `CollaborationSpace.jsx` / `App.jsx`：轻量卡片、目标及动态范围编辑、侧栏补充/通知选择/草稿保留、添加到主输入框。
