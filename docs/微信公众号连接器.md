# 微信公众号公共连接器

这是 DuolaWork 的共享服务器连接器，不依附某位 Agent 的终端或私有脚本。多个公众号使用相同入口，每个账号各有凭证、令牌缓存、调用记录和可关闭的成员/聊天范围。默认工作区成员和后续新建聊天均可使用。

## 用户入口

连接器 → 微信公众号 → 填公众号名称、AppID、AppSecret。保存时自动加密进 Vault，程序记录凭证引用，不把密钥放进连接器元数据。也可选已有 Vault 凭证，字段为 `app_id`、`app_secret`。

页面显示共享服务器配置的实际出口 IP。微信开发者平台当前入口为「基础信息 → 开发密钥 / API IP 白名单」；添加服务器 IP 时保留已有地址。不要用 Agent 所在机器或用户电脑的地址替代实际执行端。多账号通过卡片上的「添加另一个账号」接入；AppID 标识账号，原连接改密钥不变成另一个账号。

## Agent 入口

使用原聊天的 `channelId`，通过现有 `connector` 工具：

1. `connections` 查询账号，按名称、AppID 选择 `connectionId`。
2. `tools` 取该账号的工具定义。
3. `call` 执行业务，携带唯一 `requestId`。

可直接将用户提供的凭证保存到 Vault，然后执行 `connect(provider="wechat-mp", appId, credentialId, name, requestId)`。保留真实调用身份，遵守用户后置关闭的权限，不要求秘书身份。接入失败保留原账号与凭证，可以修正配置后继续检查。

提供的业务工具：

- `wechat_status`：实际探测草稿、素材、已发表记录的接口权限。
- `wechat_upload`：共享 `fileId`、公开 HTTPS 图片或小文件 base64；支持永久素材、临时素材、正文图片。上传的是文件字节，不是另一台机器的路径。
- `wechat_draft`：创建、读取、更新、删除、列表与数量；Markdown 转微信内联样式 HTML。正文图片须先上传再替换为微信返回的 URL。
- `wechat_api`：统一调用官方业务接口，包括发表、发表状态、菜单、客服等；账号实际权限由微信判断。`publish_id` 表示已提交，仍需查询发表状态；发表和向粉丝群发是不同动作。

## 稳定性与状态

使用官方 `stable_token`，按公众号独立加密缓存；过期前刷新，同账号并发刷新合并。只有微信明确返回令牌无效/过期时自动刷新并重试一次。网络断开、写入超时等结果未知时不自动重放，凭原 `requestId`/`invocationId` 查询调用记录。

Vault 轮换后缓存失效。调用前后校验凭证版本、连接版本及用户的关闭设置，旧授权不得在撤销后交回结果。请求与错误回执隐藏 AppSecret/访问令牌；不隐藏作为账号标识的公开 AppID。

`40164` 指向执行服务器 IP 白名单；`40125` 指向密钥；`48001` 表示微信没有向此账号开放当前接口。连接认证成功不等于所有业务接口可用；能力探测与真实写入、公开发表分别记录。验收使用临时素材和草稿并清理，不公开发表测试文章。

## 运维配置与验证

共享服务器私有 `server.json` 设置 `connectorEgressIp`，对前端仅提供该公开地址；没有配置时明确显示未知，不写死某个用户的 VPS。凭证与加密密钥继续保存在程序/Git 之外。

受控验证：`node --test tests/wechat-connector.test.mjs tests/service-store.test.mjs`，构建后运行 `node tests/wechat-connector-ui.mjs`。隔离样本覆盖双账号、不同 Agent/群、默认共享与后置拒绝、共享文件字节、令牌并发续期和轮换、写入幂等及结果未知。真实账号验收见 `evidence/wechat-connector-20261109.json`，不能用受控样本替代线上读写结果。

官方接口资料：[草稿创建](https://developers.weixin.qq.com/doc/offiaccount/Draft_Box/Add_draft.html)、[永久素材](https://developers.weixin.qq.com/doc/offiaccount/Asset_Management/Adding_Permanent_Assets.html)、[发表](https://developers.weixin.qq.com/doc/offiaccount/Publish/Publish.html)。不同账号的当前准入以官方接口实际回执为准。
