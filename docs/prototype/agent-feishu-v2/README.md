# Agent Hub 2.0 · 可操作 UI

2026-10-29，Codex。按[两张视觉参考](../../ui-review-20261029/README.md)与[2.0 产品方案](../../2.0改版方案.md)实现的 React/Tiptap 界面。重点是新产品逻辑和视觉、操作体验；这里不是正式桌面客户端，也没有连接真实 Agent。

## 直接使用

本机预览：<http://127.0.0.1:8872/>。也可以用浏览器直接打开本目录 `index.html`；它自带脚本和样式，无 CDN 依赖。不同入口的浏览器本机数据互相独立。

```sh
node docs/prototype/agent-feishu-v2/build.mjs
python3 -m http.server 8872 --bind 127.0.0.1 --directory docs/prototype/agent-feishu-v2
```

预览使用独立的 `agent-hub-2-ui-preview-v1` 存储键。修改保存在当前浏览器，可从设置导出工作区。没有重建、复制或删除正式账号、Cookie、钥匙串、旧原型存储；没有修改 VPN、代理或正式服务。

## 已实现的路径

- **说目标 → 工作安排：** 目标、交付标准、参与成员、独立完成／并行研究／顺序接力／执行复核四种方式；项目分工与操作范围、空结果约定、日程、下一轮安排。模板只是预填，不强制三步内容流程，不按平台品牌固定岗位。
- **项目群聊 → 审阅：** 项目主体总进入群聊，审阅是独立动作；紧凑交接可展开，成果、材料、本群成员可切换；消息支持指定成员、真实富文本格式、文本资料附件、未发输入恢复。
- **成果 → 改稿：** 工作稿可编辑、复制和导出。修改要求与全文、版本、接收成员一起保留；候选先对比，提交后继续编辑时需要明确确认替换；应用前的稿件进入可恢复历史。每份稿的要求独立，原始交付保持只读。
- **判断 → 改进：** 取舍事项展示依据和选择，决定留痕；规则修订另建待批准版本，旧版保留；批准后试行，记录复查，再保留或撤回。撤回修订可恢复旧规则。复制、导出不算采用，评价绑定实际稿件版本。
- **管理：** 资料与规则搜索/项目过滤、同平台多个独立成员、暂停参与、日程设置、工作区导出、存储失败就地提示。运行演示必须手动推进，暂停后不会继续。

默认白底、蓝色强调、浅色导航。1440px 展开四区，窄窗口收起次要栏；审阅时正文优先，修改侧栏关闭后仍停留在当前稿件。

## 验证结果

执行 `node docs/prototype/agent-feishu-v2/verify.mjs`。脚本自行启动临时静态服务器、使用独立临时 Chrome 上下文，结束时关闭自己的浏览器和服务器。`UI_CHROME_PATH` 可指定 Chrome 可执行文件。

本轮 **23 项自动化检查通过**，详见 [checks.json](evidence/checks.json)：涵盖跨稿/刷新恢复、完整改稿快照、冲突确认与历史恢复、采用语义、输入法组词事件不误发、规则修订及撤回、同平台成员隔离、四种安排、日程格式校验与去重、项目授权持久化、暂停、导出、存储失败拦截和页面尺寸。检查期间没有 JavaScript 运行错误，没有对外或 Agent 网络请求。

正文滚动区占审阅面板：1440×900 为 722/871（82.9%）；1280×800 与 900×800 为 622/771（80.7%）。这些尺寸不是用户观感认可，也不是正式客户端验收。

## 接线边界

示例数据、示例成果和手动运行明确标注。消息与改稿要求只保留在预览，不发给真实 Agent；保存日程不启动后台任务；权限字段不授予真实平台权限；规则试行是可操作的本地交互，不等于后台已经注入规则或自动验证有效性。

正式 API/事件流、原生 Agent 执行、服务端权限和并发版本校验、真实定时唤醒、模板管理库、全局资料及读取权限、账号连接诊断仍须与 2.0 后端联调。这版不声称通过产品方案全部 42 项验收。原生 Mac 中文输入法、浏览器实际缩放、正式桌面退出重开仍须在正式客户端联测；当前只验证浏览器刷新和合成组词事件。
