# DuolaWork Vault：全局凭证库

2026-11-09 所有者修订：Vault 按 Agent Native 默认开放新增、读取、改值/轮换、启停、删除/恢复、备份和使用。用户已给凭证时由 Agent 直接保存，不要求人类在页面代填。下面已同步当前产品边界；2026-11-08 的实施记录保留为历史证据。

## 定位和用户约定

Vault 是工作区级的独立凭证库；连接器负责调用外部服务，Skill 是做事方法，原 Agent 的登录仍在其原环境。你保存一次 API Key、Token、账号密码、SSH 私钥或自定义字段，全体 Agent 在各自工作中按需使用。默认包括以后新加的成员和聊天；需要时在单条凭证中关闭某个成员或群，无逐次审批。

不扫描用户的浏览器密码或原 Agent 登录。管理用户明确提供或要求保存的凭证，Agent 可以直接录入；不回显到群聊、Todo 或记忆。没有凭证时显示空库，不造示例密钥或假连接。

## 调研结论与选型

| 一手方案 | 可复用的设计 | 本轮选择 |
|---|---|---|
| 1Password CLI | secret reference URI、进程环境注入、默认输出遮盖 | 采用引用和执行时注入的交互；不要求每个 Agent 单独订阅或登录 1Password |
| Infisical Agent Vault（预览） | 凭证由代理添加到 HTTP/MCP 请求，模型使用能力而非保存密钥 | 采用凭证代理，不接管用户全部网络或安装 MITM 根证书 |
| Infisical 自托管 | 集中存储及审计，依赖 PostgreSQL 和 Redis；官方 small 建议每应用实例 4GB 内存 | 当前 1GB VPS 不额外部署完整 Infisical 服务端；以现有工作区身份与成熟 Web Crypto 构建独立轻量模块 |
| HashiCorp Vault response wrapping | 短时、一次使用、可追踪的领取 | 原生环境领取绑定当前成员、聊天、字段和版本；撤销或版本变化后旧领取失效 |
| OWASP Secrets Management | 加密、凭证与密钥分离、轮换、撤销、审计、备份恢复 | 纳入本轮存储和验收，不把默认共享等同匿名访问 |

此为基于资料与当前部署资源的设计判断，不宣称与上述产品等价、兼容其协议或获得其安全认证。

## 人的使用路径

侧边栏增加独立「Vault」入口，页面标题「全局凭证库」。列表显示名称、类型、服务、状态和最近使用时间，不显示值或值尾号。支持搜索、添加、编辑/轮换、停用/启用、删除/恢复、使用记录。

添加时只填名称、类型和字段值；用户或 Agent 都能保存。服务地址可选，留空时正常使用，不要求先填白名单；用户主动指定后按该范围执行。「使用范围」折叠后置，勾选关闭成员/聊天。更新保留同一 ID，旧引用继续指向新值。编辑默认不回填秘密；留空保留原值，修改值才轮换。账号密码和多行私钥分别支持正常录入。

用户和 Agent 均可按需读取真实值；普通列表仍只返回名称和字段引用。页面查看结果不缓存、不写入 UI 草稿，切出或关闭时清空。用户已向 Agent 提供凭证并要求保存时，Agent 直接调用保存工具，不让用户再填一次，也不把值回显到聊天。删除先进入回收站并停止后续使用，可恢复；彻底删除是明确要求后的单独动作。

提供密码加密备份与导入。备份包含密文，导入先完整校验再创建新条目，不覆盖现有凭证，不把导入变为后台自动授权到原平台。

## Agent 的三条使用路径

1. 所有成员共用云端 vault 工具：save 直接新增或修改字段，reveal 按需读取真实值，普通列表返回字段引用；启停、删除/恢复和备份也向普通 Agent 开放。HTTP 代请求在服务端注入凭证，默认无需预设服务地址；用户已主动指定范围时按该范围执行。拒绝重定向和私网地址；写请求唯一编号、结果不明不自动重放。
2. 共享连接器：HTTP 请求头或本机/VPS MCP 的环境变量中使用 vault://凭证ID/字段 引用。执行时解析，配置不保存重复的真实密钥。连接器范围与 Vault 范围取交集，任一关闭均拒绝。轮换后下一次执行使用新版本。
3. 原生 Coding Agent：提供 run_with_credentials 本地工具，或经原生 Hub CLI 调用。只在该 Agent 所在环境启动明确指定的子进程，按映射注入字段；输出遮盖已知秘密，不把密钥作为结果传给模型。无需改变原模型、登录、项目或 shell 全局环境。旧客户端可先使用 HTTP 代请求；本轮同时更新原生工具目录与下载运行包，不把未更新的本地运行端冒充具备该能力。

普通列表返回引用，Agent 也可按任务需要显式读取值；执行时优先引用注入，减少重复复制。领取值的运行端使用本成员身份，领取绑定成员/聊天/字段/版本，短时有效且一次使用。被关闭访问、停用、删除或轮换后旧领取失效。进程退出后不保留环境文件；本版不声称能约束拥有执行权限的恶意脚本。

## 存储、权限与错误边界

- 独立随机 256 位 Vault 主密钥，与管理 API 密钥分离，保存在程序目录外的受保护文件。使用 Web Crypto AES-GCM，随机 IV，认证附加数据绑定工作区、条目 ID 与版本。数据库、事务回执和审计均不保存明文。
- 主密钥首次创建后不因部署/重启重新生成；已有密文而密钥缺失/损坏时，Vault 报锁定，保留现场，其他产品功能可继续。备份需保存独立的恢复材料，不能把数据库复制当作完整恢复。部署会将恢复密钥另存到本机私有 server-deploy/vault-recovery 目录（0600），不打入 Git、程序包或数据库快照；数据库备份只记录密钥指纹。用户的密码加密导出包可在新服务重新导入，不依赖旧主密钥。
- 全局是当前工作区，不是所有租户。所有入口都使用现有真实成员身份、聊天成员关系和新鲜权限检查；匿名、另一成员的领取、另一工作区、停用成员、过期版本均拒绝。
- 默认所有已接入 Agent 可管理真实值和生命周期，无需秘书身份或逐次审批；用户可后置关闭成员/群或指定服务范围，Agent 不能改写这些关闭设置。旧平台缓存工具目录时，使用既有 post_message 的 HUB_SHARED_TOOL_V1 入口传 save/fields，不要求重登或新建成员。没有真实服务方凭证不显示可用。
- 审计记录谁、在哪个群、使用哪条凭证/哪个版本、方式、时间和结果，不记录值、请求体或完整响应。普通聊天、Todo、记忆、变更订阅不注入凭证正文。
- 运行端/第三方已取得的旧值无法远程收回；关闭本系统权限只阻止后续使用，需要服务方撤销的密钥应在服务方轮换。已执行的网络写操作不因权限撤销自动撤回。
- 密钥代理避免直接提供值，但上游可能返回新签发的秘密；已知值遮盖不等于识别所有新秘密，不作为绝对防泄漏保证。

## 验收标准

A. 加密存储和重启恢复：数据库、回执、记录无测试秘密；工作区/ID/版本错配无法解密；主密钥更新不被隐式重建。
B. 默认共享与撤销：不同成员/不同群和后来新群默认可用；关闭成员或群后立即拒绝；停用、删除、轮换使旧领取失效；恢复行为可查。
C. HTTP 真实往返：只给允许地址注入、拒绝跨站/私网/重定向；结果遮盖，超时不重复写；并发同编号只执行一次。
D. MCP 真实往返：远程 HTTP 与 stdio 环境变量均从同一凭证引用解析；两个成员共享；轮换无需复制；调用与运行端回传时再次检查撤销。
E. 原生执行：实际子进程收到正确字段，另一个成员不能领取；返回结果和日志不含已知秘密；不改变全局环境或原 Agent 登录。
F. 备份恢复：密码正确可导入并读回完全相同字段；错密码、损坏包、重复导入请求不产生部分条目或重复副本。
G. 人类 UI：添加、搜索、编辑、查看/复制、权限、删除/恢复、使用记录和备份均可操作；窄屏不溢出；秘密不进入 localStorage。
H. 发布：完整自动回归、类型检查、资料保护门槛、打包、实际客户端启用、VPS 生效和独立审阅；源代码/候选测试/真实 Agent 回传各自记录，不混称。
