## 二、方案一句话

**一人公司的 AI 团队：把你已经在用的大厂 Agent 按岗位组成团队，跨生态接力干活。工作台先帮你把团队搭起来，再帮你派活、盯进度、收结果。**

## 三、解决什么问题

1. **不知道怎么搭**（最大的）：该让哪家干什么、在哪里设置、跟它说什么。→ 首次使用向导，20 分钟搭好。
2. **跨生态只能自己当中间人**：X 在 Grok 手里、Gmail 在 Gemini 手里、Instagram 在 Muse 手里。→ 工作台当中间人，它们接力。

## 四、用户拿到什么

| 东西 | 是什么 |
|---|---|
| 首次使用向导 | 6 步：讲生意 → 选要做的事 → 选你的 Agent → 一个一个连上 → 定规则 → 试跑 |
| 公司档案 | 业务、客户、语气、目标、禁区，讲一次，所有 Agent 都知道 |
| 团队 | 4 个岗位：社媒经理、行政助理、获客、内容核实；每个岗位交给握着对应生态的 Agent |
| 例行工作 | 比如每天 08:00 出一份 X 内容包；平时不打扰，只在要你确认时找你 |
| 接力任务 | 跨岗位、跨 Agent 的多步任务，例如：Grok 抓热点 → Dots 核实 → Gemini 写稿 → Muse 改 Threads 版 → 你确认 |
| 确认中心、时间线 | 所有要你点头的事在一处；每一步谁做的、交了什么都有记录 |

**适合：** 跨生态、重复发生、不着急的事。**不适合：** "我现在就要"的事。

## 五、怎么实现

- 工作台跑在 Cloudflare Workers 上（免费额度够第一版）。
- Agent 通过标准 MCP 来调用工作台的 6 个工具（测试连接、查看我的任务、领取、提交、读档案、写档案）；Muse 用普通接口。
- 工作台不能调用 Agent，只能**叫醒**：Grok 用 webhook，Dots 用 Slack @（待实测），Gemini 用触发邮件，其他靠它们自己定时来查。
- 认证三种都支持：不认证（ChatGPT）、API Key（Grok）、OAuth（Gemini）。
- 平台差异全在配置里，新增平台不改代码。

## 六、能接哪些 Agent

| 档位 | 平台 |
|---|---|
| 能接 | Grok Bot、ChatGPT Dots、Gemini Tasks、Perplexity Computer、腾讯 WorkBuddy、千问办公、OpenClaw、Hermes |
| 需要实测 | Meta Muse、豆包工作、Kimi |
| 暂不支持 | Instinct、Microsoft Copilot、智谱 AutoGLM |
| 不做 | Claude Duet |

## 七、竞争和定位

| | 我们 | AI 员工产品（Sintra、Marblism） | Paperclip |
|---|---|---|---|
| Agent | 用户已有的大厂 Agent | 自己造的 | 用户自己部署的 |
| 优势 | 最强能力，天生连着用户的账号；不用懂技术 | 开箱即用 | 能直接调用，控制力强 |
| 弱点 | 控制权在大厂；接力慢；有地区限制；护城河要自己积累 | 能力和能接的工具有限；额度和退款被诟病 | 要懂技术、自己部署 |

## 八、风险（按大小）

1. **接力是不是真的比"一个 Agent 全做"好**：决定产品有没有价值。第 1 周对比。
2. **各家实际能不能接上、叫醒能不能用**：M0 实测。
3. **20 分钟能不能搭好**：决定读者会不会半路放弃。
4. **Agent 会不会照做**：靠实测过的接入原话 + 时间线兜底。
5. **大厂改规则、Paperclip 跟进**：差异放配置里；靠档案、模板、接入体验积累壁垒。

## 九、时间表

| 时间 | 做什么 | 过关标准 |
|---|---|---|
| M0（半天） | 最小服务，你把手上的 Agent 逐个接上 | 至少 3 家接上；两家以上接不上就改方案 |
| 第 1 周（M1～M4） | 做出自用版；你走一遍向导；四家接力 vs 只用 Dots 对比 | 20 分钟搭好；内容包每天跑完；接力明显更好 |
| 第 2 周（M5） | 你每天用 | 连续 7 天在用 |
| 第 3～4 周 | 10～20 个读者试用；在 X 上问"搬运痛不痛" | 一周留存过半；有人问价格 |

## 十、需要你做的

1. 确认「每日 X 内容包」的分工，以及 Gemini 要不要挪到最后（它每次交结果都要你手动确认，放中间会卡住后面）。
2. 第一版要不要优先实测别家（千问办公、Perplexity 等）。
3. M0：提供 Cloudflare API 令牌；在每个 Agent 里按指引操作几分钟。
