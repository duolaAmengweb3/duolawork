用户已要求把评审方案一次完成。任务：连接器与技能完善（`board_fd59beea933f4ea484e6c7e5a0e6c814`）。本页记录实际行为与验证层次，不把协议通过说成各厂商原生安装完成。

## 使用方式

连接器页保留 GitHub 账号、仓库及聊天/成员范围，增加“检查读取”“查看读取记录”。检查实际读取一个已关联仓库；历史显示来源、时间、执行人、结果与耗时。授权仍有效时无需重登。401、403 权限、403/429 限流、404 不存在或不可见、网络和超时分别提示；404 不假装能确定具体原因。配置版本在请求返回后再次校验，期间撤销则不返回资源。密钥、资料正文不写使用记录。

技能页显示“可供使用”，展开后看环境要求、完整资源、版本来源、每次使用与核验。导入文件夹保留脚本、引用及二进制资源；公开 GitHub 目录或 SKILL.md 链接先解析到 commit，再按该版本导入整个技能目录。拒绝符号链接、目录穿越、超限包和不完整读取；产品限制为 40 文件、150KB。正文引用未带来的资源会提示，不声称可直接运行任意来源。

任务可以选多个技能并保存当时版本，新建子 Todo 默认沿用父任务选定版本。后续技能更新不改旧任务。移动已有 Todo 只调整归属，不偷偷重写已选方法；用户可在编辑时主动改变。停用后不能再读取，但仍可记录新的待办，历史任务和人类可见的使用记录不丢失。没有指定技能时，成员仍可按任务需要选用，不阻止普通聊天。

## 实现与边界

- `read_skill` 默认读取任务固定版本，或明确指定版本；返回资源字节散列、编码与 readId。目录摘要不塞入全部技能正文。
- `report_skill_use` 记录具体成员、任务、版本、readId、实际环境、依赖检查和产物。旧版本回报必须引用该成员实际读取的对应记录；缺必要依赖不能声称使用成功。执行记录是成员报告，不冒充服务器运行或独立验证。
- `review_skill_use` 核验一次使用，关联实际任务/产物；其他成员需提供来源，人类可直接写实际核对依据。拒绝自我独立核验。核验不改变技能的全局可用状态，也不自动发群消息。
- `save_method` 由成员结合实际工作保存本群方法，必须有来源、适用条件、局限；可保存草稿。原作者、负责人或有工作区委托的管理者修订，保留版本。引用本群资料的方法不能直接扩为全工作区；来源删除/失效后不再供 Agent 召回。方法非强制群规，不从“多人赞同”推断人类决定。
- 原有 `skill_use` 记录按原字节保留，查询兼容新格式；不虚构过去的 readId、执行环境或验收。
- 旧原生工具目录可通过 `HUB_SHARED_TOOL_V1` 兼容入口调用新增工具及参数，无需重新登录。
- Hub 不替代原生 IDE/终端，不在服务器执行技能包脚本。环境与依赖由实际 Agent 检查并回报；模型能力、未执行脚本、未知依赖不会标为已通过。
- 保留既有开放范围语义；界面明确“所有聊天/成员，包括以后新增”。当前共享连接器交付为 GitHub 只读。飞书等第二连接器、外部写动作尚无具体资源及授权选型，不擅自承诺已实现。
