# 通用连接器实施与验收

状态：候选验收通过，准备发布。用户要求本轮一次完成、上线；下面明确功能与验证层次，发布后补充实际构建号。

## 用户决定

- 外部账号完成一次服务方授权后，默认向本工作区全部 Agent、全部聊天开放，包括以后新增的成员与聊天。
- 权限管理后置：在连接详情勾选要关闭访问的成员或聊天。已有连接的指定范围保留，不借升级扩大旧授权。
- 连接器统一提供外部能力；Skill 提供做事方法。连接器目录与通用 MCP 接入同时提供，不逐家、逐模型重做工具。
- 原 Agent 保留自己的账号、会话、项目和已有工具。MCP 工具在连接指定的位置运行；云工具不会因接入而获得用户本机文件能力。

## 本轮功能

1. 远程 MCP：官方 TypeScript SDK 处理 Streamable HTTP、旧 SSE 兼容、会话、工具分页及执行。按需取工具定义，使用统一的 `connector` 工具调用，不把全部服务工具塞到每次聊天中。
2. 登录：支持 OAuth 元数据发现、动态注册或客户端元数据文档、PKCE、回调状态校验、一次消费与令牌刷新；支持已有请求头/令牌、无需认证的服务，以及需预注册应用的高级配置。长期凭证服务端加密，不分发给模型。
3. 服务目录：GitHub、Cloudflare、Vercel、飞书、Notion、Google Drive、Gmail、Google Calendar、Figma、自定义。目录不代表该用户的账号已经连接。飞书使用服务方生成的 MCP 地址；Google 官方预览仍受服务方准入和项目配置限制。
4. 多个账号：同一服务可添加多个有名称的独立连接。原 GitHub 只读连接、仓库与授权继续可用。
5. 本机/VPS：用户添加独立的共享工具运行端；桌面版可直接使用这台电脑，其他机器复制一次性接入说明。运行端向外连接，无需给机器开放入站端口；只启动所配置的 MCP 进程，不启动替代 Agent。Linux systemd / macOS launchd 可用时自动安装自己的后台服务；系统不支持时明确报告仅后台运行。
6. 配置导入：接受 `mcpServers` / `servers`，保留多个远程地址、请求头及 stdio 命令、参数、环境变量；指定工具运行位置。失败逐项保留真实原因，不称为整包成功。
7. 调用与恢复：唯一请求编号与持久调用记录防止并发重复执行。网络中断后结果不明的写操作不自动重放；运行端回传直接保存结果，原 HTTP 请求退出也可查询。执行中、成功、失败、结果待核对分开显示。
8. 授权范围变化前后均检查；断开阻止后续执行，已读内容不声称可从模型中抹除。远程请求限制公开 HTTPS，VPS 服务的 DNS 校验与实际 socket 使用同一解析结果；内网工具通过用户指定运行端执行。
9. 原平台缓存旧工具目录时，保留 `post_message` 的既有兼容封装入口，不要求重登录或新建 Agent。

## 候选验收

- 专项协议：同一连接给多位成员与新群使用、多账号、后置关闭、并发幂等、结果不明不重放、调用期间撤销不返回数据、真实 stdio 子进程、旧工具入口、OAuth 全流程、自动刷新与并发轮换、旧 SSE。见 `tests/mcp-connectors.test.mjs`。
- 浏览器 + 真实 HTTP + stdio：目录、默认共享、这台电脑接入、两位独立协议成员使用、关闭名单持久化、配置导入与 390px 布局。见 `tests/mcp-connectors-ui.mjs`。
- 真实上游只读：已通过 Cloudflare 公共文档 MCP 的工具发现及 `search_cloudflare_documentation` 调用，得到真实文本结果。此项验证公共工具，不冒充 Cloudflare 账号资源访问。
- Cloudflare、Vercel、Notion、Figma 官方端点已实际返回 OAuth 认证要求。没有替用户点击服务方授权；未授权账号的完整访问必须保持“需要登录”，不能用隔离样本冒充。
- 服务 Logo 来自 Simple Icons 的对应 SVG，随包提供，不在用户页面请求外部图标服务；飞书未拿到可核实的 Logo 时保留通用图标。
