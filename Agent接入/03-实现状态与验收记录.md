## 验收记录怎么追加

每次只加一行：日期、Agent/版本、具体操作、真实结果、证据位置、是否安装生效。修好后补复验记录，不删除原失败。原生会话、Hub 消息和本地文件的实际结果需要互相对得上。

本轮 Coding 路线：Codex 官方 App Server + Gemini 官方 Antigravity ACP，工程方案固定。后续按同一条路线维护，新增平台单独验收，不重开泛调研，也不把本次通过推成全部目标已支持。
