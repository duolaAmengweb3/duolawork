## 3. 本轮只新增的事实

- 本机 Codex 的 App Server 识别到 ChatGPT 登录，并已真实领取、回传接入验证；未改变 provider/model。
- 旧 Gemini CLI 0.61.0 能完成 ACP 握手，但个人 OAuth 建立会话时返回“不再支持此客户端，请迁移到 Antigravity”。这是一条明确实测错误，不是推测账号被封。
- 本机已有 Antigravity CLI 1.3.3，以现有登录完成真实回复。随后调用 Hub MCP 被原生权限拒绝，未擅自放宽全局权限，也未伪报接入完成。
- T3 Code 已有官方 Antigravity ACP 集成、独立认证和安装实现。这是本轮用于解决具体卡点的补充依据，后续直接据此实现，不再重复泛调研。

## 2026-11-04 Antigravity 原桌面落地依据

继续复用既有 Sidecar + agentapi 路线。官方文档 https://antigravity.google/docs/sidecars/ 明确列出 App 的 Sidecar 生命周期、私有运行目录和向已有 conversation_id 发送消息的方法。本轮在已安装 2.28.0 的公开程序包和真实继承环境中核对：只读 GetAllCascadeTrajectories 提供标题、工作目录、运行状态；工作中的 RUNNING/BUSY/CANCELING 均等待，仅 IDLE 发送。未知状态也不猜测空闲。列表接口按明确版本适配，不将它当作未来不变的公共协议。

本轮实现继承官方 Sidecar 环境进行本机鉴权，不从原 App 提取 CSRF 或 Google 登录文件。native send 通过官方多调用二进制的 agentapi 子命令，未换成模型 API。无需再研究另一套浏览器或新会话方案；实际产品化证据统一在 03。


## 11月4日：多 Codex 与聊天会话绑定核对

[官方 Codex App Server 文档](https://developers.openai.com/codex/app-server/)明确区分 thread/start、thread/resume、thread/read、thread/loaded/list，以及线程与推理 turn。已打开原生线程可通过只读元数据找到；本机官方 `codex queue --help` 确认支持精确 thread 与 remote，不加 --resume 即不在另一执行端恢复它。本轮用原 daemon 创建的专用会话先记住仅在对话里的识别词，加入 Hub 聊天后由原会话实际领取、回传识别词；证据为 codex-chat-binding-native.json。这里没有重新操作所有 GUI 版本，不能扩大证据范围。

实际集成测试暴露旧服务按 accountId 锁定资源：同账号两位原生工作成员并发领取被拒。修正为受支持 Coding 平台的独立成员资源锁后，同账号两位真实 Codex 能在同群独立回应；不是只改前端显示名称。

Antigravity 官方桌面当前只交付选择已有原会话，未实现的原生新建不显示按钮。DSH 原生 Host 则已有 create 接口，可在原 Host 新建。Grok 与 Dot 保留原生身份，不因为产品叫 Personal Agent 就假设所有平台都有或都没有会话 API。

## 11月4日本轮：接入简化与账号入口纠偏

继续采用上表 T3 Code/Zed 的原生运行协议组织方式，以及 botline/Paperclip 的外部 Agent 接入思路；这些不是一套可以不加适配就覆盖全部平台和多设备账号的成品。旧 UI 把技术复用选项当作用户的“添加账号”，已纠正。当前用户明确的账号→多工作会话模型是本轮产品约束；不能声称竞品已经替我们完成。

Claude 的 [官方 Channels 说明](https://code.claude.com/docs/en/channels) 与 [开发接口](https://code.claude.com/docs/en/channels-reference) 本轮重新核对：标准 MCP stdio、实验 capability、Channel notification 可复用；自定义通道首次需要启动参数与官方确认，不能靠一段 Skill 宣称已在运行中的会话热启用。说明自动化的是安装、校验、配对与状态报告。头像优先取已安装官方应用的产品图标（Codex、Grok Bot、Dot、Antigravity、DSH），其他使用官网图标；Dot 为原包 DotIcon 的静态 SVG，形状和配色未改。来源与内容哈希在 `ui/assets/brands/sources.json`；不改造 Logo，不代表官方背书或新增接入支持。
