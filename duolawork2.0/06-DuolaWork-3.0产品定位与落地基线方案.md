# DuolaWork 3.0 产品定位与落地基线方案

日期：2026-11-27 · 状态：**已拍板定稿（3.0 全量工程落地对齐基线）**

> **核心原则**：DuolaWork 3.0 **不是推翻 2.0 架构重写**，而是在 2.0 稳固底座（单线程有界增量交接、负责人验收任务状态机、定时跨期隔离、多标签独立阅读器、本地桌面 + 云端控制面双端同步）之上，**彻底钉死市场定位、锚定已验证付费竞品、打穿首次上手到日常留存的产品闭环**。

## 2. 竞品坐标与差异化壁垒（为什么不是空白市场）

基于 2025–2026 真实市场格局，DuolaWork 3.0 精准卡位在以下四类成熟产品的**痛点交叉口**：

| 成熟竞品阵营 | 代表产品与收费 | 市场已验证需求 | 竞品真实高频痛点 | DuolaWork 3.0 的直击差异化 |
| --- | --- | --- | --- | --- |
| **单厂商桌面 Cowork** | **Claude Cowork** ($20–$200/月)、ChatGPT Work、Copilot Cowork | 桌面端直接处理本地文件、跑定时日常任务、输出结构化交付 | 厂商锁死单家模型；多步任务极易撞 5 小时限流；无多 Agent 验收与精排多标签阅读器 | **多模型/多订阅原生混编**（Codex + Gemini + Claude + Grok 同一对话接力）+ 负责人自动验收 + 多标签精排阅读器 |
| **开源多 CLI 聚合壳** | **AionUi**、**OpenWork** | 自带订阅/API 聚合多款 CLI、本地 SQLite 存储、跑本地定时 | 偏极客工具箱，缺少“负责人拆单 → 执行人独立会话/Worktree → 自动打回验收”的交付闭环与文档版本管理 | **内置确定性任务验收状态机 + 乐观锁文档协作空间 + 桌面/云端双端同步** |
| **黑盒全自动云 Agent** | **Manus** ($20–$200/月)、**Genspark** ($20–$25/月)、**YouMind** ($20–$40/月)、**Lindy** ($30–$199/月) | 深度调研、报告产出、数据清洗、日常运营自动化 | **黑盒积分抽税极重**（跑偏即废、月底清零）；不能复用用户已有顶级订阅；难以中途无缝接管改稿 | **零积分抽税（BYOS）** + 执行过程透明可随时人工接管编辑 + 定时任务跨期隔离不卡死 |
| **纯编码调度 / 公司控制面** | **T3 Code**、**Conductor**、**Paperclip AI**、**OpenClaw** | 多 Worktree 并行编码、7×24 本地自治、多 Agent 组织调度 | T3 Code 只管写代码，不管方案文档/数据表/运营定时；OpenClaw 运维折腾且裸奔安全风险高；Paperclip 像重型工单后台，缺乏自然协作与成果阅读体验 | **从调研文档 → 写代码 Worktree → CSV/报告审阅 → 定时巡检全链路一张桌**；零守护进程运维，最小权限沙盒 |

### 3.0 明确不做的事（Non-Goals / 防范围蔓延红线）
1. **不和 T3 Code / Cursor 卷纯 IDE 级写代码细节**（如内联行级代码补全、复杂 Git Rebase 图形器）——代码是交付闭环中的一环，不是全部。
2. **绝不退回 1.x 多人群聊自由广播**——坚持唯一 `+ 新对话`、单线程当前负责人、`12 KiB` 有界增量交接与 5 类确定性唤醒白名单。
3. **不做黑盒转卖算力/积分的云端套壳**——始终坚持原生 Agent 与自带订阅（BYOS）。
4. **不做大企业重型 OA / 复杂低代码拖拉拽编排器**——需求一律自然语言表达，拆单/定时/验收由负责人 Agent 理解并结构化落地。

## 3. 三大标杆工作流（Golden Workflows）

3.0 的产品交互、空态模板、演示脚本与验收全部围绕这 **3 个高频真实场景**展开：

### 场景一：方案定稿 → 同线程切人写代码落地（T3 Code 上游延伸）
- **触发时刻**：独立开发者 / Tech Lead 要做一个新功能或改版。
- **标准闭环**：
  1. 在新对话里先和 **Gemini / Claude** 讨论方案，右侧协作空间实时生成 Markdown 方案文档；
  2. 点击「独立窗口打开」，在多标签阅读器里精排阅读、局部手动改稿并保存（乐观锁防覆盖）；
  3. 回到同一对话左下角直接切换为 **Codex**（静默带入 `12 KiB` 有界增量上下文 + 最新定稿指针），让 Codex 基于定稿开独立 Git Worktree 实现代码并跑测试；
  4. 代码变更摘要与测试结果回流对话与空间，必要时切回原负责人做复核。

### 场景二：跨 Agent 调研 + 数据产出 + 定时自动验收（替代高价 Manus / Lindy）
- **触发时刻**：一人公司 / 产品经理 / 运营需要出一份深度竞品/市场报告，或每周固定跟踪数据与竞品动态。
- **标准闭环**：
  1. 在对话里点击「指派任务」→ 选择「一次性」或「循环定时」→ 一句话描述需求（频率未说清时由负责人通过追问卡反问确认）；
  2. 负责人拆单并行/串行派发：如 **Grok** 抓一手社媒动态 → **Codex** 用脚本清洗分析产出 CSV 数据表 → **Gemini** 整合撰写结构化 Markdown 研报；
  3. 每步提交后系统自动唤醒**负责人核验**，不达标在原任务会话自动打回返工（上限防死循环），无需人类当监工；
  4. 全部验收通过后主对话只推回一张清爽的**交付结果卡**；定时任务每期独立运行，单期失败绝不堵死下一期。

### 场景三：多格式成果集中审阅、批注与人工接管（超越单聊文件堆砌）
- **触发时刻**：任务交付后，需要同时对照多份文档、数据表、配置文件、源码与截图做最终拍板。
- **标准闭环**：
  1. 在协作空间点击任意文档/文件，全部在**同一个独立多标签阅读窗口**里并排打开（支持 `+` 快速拉取当前对话其他资料）；
  2. **Markdown** 享受纸面精排（浅色 / 护眼米黄 / 深色 3 主题 + 目录大纲 + 阅读/分屏/编辑）；**CSV/TSV** 表格对齐预览；**JSON/JSONL/代码** 带行号语法高亮；**图片/PDF/音视频/HTML** 原生安全预览；**Office/压缩包** 明确标识与原件下载；
  3. 人工在阅读器里直接修改定稿，跨端实时同步回主工作台，或直接把修改意见派回 Agent 继续迭代。

## 4. DuolaWork 3.0 核心升级模块（从 2.0 到 3.0 要做什么）

### 现状盘点（2.0 已完工资产）
- 底层调度与隔离：单 SQLite 账本、幂等派发、断线对账、`12 KiB` 增量交接、Worktree 集成、定时跨期防堵死、最小权限 `scopedTurnToken` 沙盒、66 项自动化回归全绿。
- 界面与阅读器：Coss UI + Tremor Raw 重构的三栏工作台、AI 原生单输入「指派任务」、长列表分页与内滚、多标签独立阅读器初版、云端 VPS + Mac 桌面端双端上线。

### 3.0 必须打穿的五大升级模块（M1–M5）

#### M1 · 多标签独立阅读器「零丢稿 & 全格式」工业级加固（P0 · 阻塞发布）
直接对齐实测审计报告 [`evidence/v2-final/product-audit-20261127-reader.md`](file:///Users/duola/Desktop/Xduola/32%E5%8F%B7-Agent-Hub/duolawork2.0/evidence/v2-final/product-audit-20261127-reader.md) 暴露的全部 10 个真实问题，全部清零后方可对外发布：
1. **【高】未保存草稿关闭保护**：点击标签 `×`、鼠标中键或 `⌘/Ctrl+W` 关闭有未保存修改的标签时，提供明确选项（保存并关闭 / 放弃修改 / 取消），与快捷键行为 100% 一致。
2. **【高】慢网并发保存不回滚新输入**：记录提交快照 `submittedContent`，仅当保存返回时编辑器内容仍等于提交快照才清除 dirty；若保存期间用户继续输入，只推进版本号并保留最新草稿与未保存标记。
3. **【高】跨端实时同步修复（SSE 对齐）**：阅读器订阅服务端真实推送的默认 `message` 事件并按 JSON `type` 分发；只读态无感刷新新版，编辑态保留草稿并高亮提示「发现新版本」，断线重连自动补拉。
4. **【高】单窗口共享一条 SSE 连接**：将 `EventSource` 从每个 `ReaderTabPane` 提升到 `DocumentPopoutView` 顶层复用，彻底消除 HTTP/1.1 下多开 6 个文档触发浏览器连接池阻塞的问题。
5. **【中】断网保存明确反馈与重试**：网络失败时清晰 toast + 顶部未保存失败态提示与一键重试，恢复网络后可正常保存并读回。
6. **【中】Office 容器识别防乱码**：对 `.docx` / `.xlsx` / `.pptx`（ZIP 容器）严格归类为 `binary` 文件信息与下载卡，杜绝输出 `PK...` 乱码。
7. **【中】扩展名与 MIME 联合判定 + JSONL 逐行格式化**：补齐 `.go/.rs/.mdx/.jsonl/.ndjson` 等扩展名识别；JSONL 支持逐条记录格式化与语法高亮。
8. **【中】CSV 大表截断显式说明**：超过预览上限（如 500 行）时明确展示「总行数 / 当前预览行数」，并提供一键查看源码或下载完整原件。
9. **【中】图片缩放按自然尺寸倍率计算**：修复小图从 100% 放大到 125% 时按容器宽度暴涨的 Bug，保证相邻倍率与标注严格一致。
10. **【中】刷新保持真实标签集合与焦点**：关闭初始标签并切到其他标签后刷新窗口，严格恢复刷新前的打开列表与激活标签（不再复活已关的 URL 初始文档）。

#### M2 · 3 分钟零配置接入体验（BYOS Auto-Discovery，P1）
解决外部新用户“装完软件不知道怎么把自己的 Agent 接进来”的最大流失点：
- **本机 Agent 自动扫描卡片**：桌面端启动或进入「成员与用量」时，自动探测本机已安装/已登录的原生 CLI 与运行时（如 `codex`、`claude`、`gemini`、本地 ACP 等），一键激活启用，无需手写配置。
- **接入状态一眼可读**：明确区分「已就绪（复用本机订阅）」「未登录（点此引导登录）」「未安装（附安装命令）」，同时保持零破坏本机原有配置的红线。
- **跨设备节点一键配对体验**：清晰展示「本机成员」与「云端 VPS 成员」分工（本机负责本地文件/代码 Worktree，云端节点负责 7×24 定时不关机）。

#### M3 · 首屏场景化起步 & 本地目录直连（Cowork 心智对齐，P1）
把 3.0 定位直接“长”在用户打开产品看到的第一屏：
- **新对话空态升级**：用 3 张可一键点选的**标杆场景起步卡**（对应「方案→代码落地」「定时调研与数据表」「本地文件整理与审阅」）替代空白页面，点击自动带入结构化提示词与推荐协作方式。
- **工作区文件夹直连强化**：在对话顶栏和右侧协作空间提供更直观的「绑定本地文件夹」入口，让非纯代码用户也能像用 Claude Cowork 一样把整个项目资料夹交由多 Agent 读写，改动产物一键进入多标签阅读器。

#### M4 · 定时任务与一人公司高频模板 + 交付可靠性（P1–P2）
- **预置 3–5 个开箱即用的一人公司/研发模板**：
  1. 每日/每周竞品与行业动态追踪（抓取 → 清洗 CSV → 研报定稿）
  2. 代码仓库巡检与周度变更复盘（扫描提交/测试 → 风险清单）
  3. 需求评审与技术方案双人复核（主笔出稿 → 红队质询 → 修订交付）
- **任务交付卡清晰化**：对话内的任务交付卡一眼展示「交付结论 + 关联产物一键进阅读器 + 验收记录 + 耗时/用量摘要」。

#### M5 · 对外叙事、文档与无假数据闭环演示（P2）
- **统一对外门面**：按 3.0 定位重写 GitHub `README.md`、官网首屏文案与竞品对比表（直接对标 Claude Cowork / Manus / Paperclip / T3 Code）。
- **90 秒真机实录 Demo（零模拟）**：基于真实在线成员录制一条端到端视频：**Gemini 讨论出方案 → 独立阅读器改稿 → 同线程切 Codex 改代码 + 生成 CSV → 定时任务自动验收回传**，全部可复现、有真实交付证据。

## 6. 商业化与产品度量指标

### 商业化分层（保持 BYOS 零积分抽税口碑）
- **Community / Local Desktop（免费 / 开源引流）**：完整本地多 Agent 混编、单线程切人、本地任务验收、多标签精排阅读器、复用用户所有自有订阅。
- **Pro Cloud（个人订阅，预估 $12–$19/月）**：云端控制面 7×24 定时托管（关电脑照常跑）、多设备实时同步、云端文档与文件版本备份。
- **Team / OPC Plus（小团队订阅，预估 $29–$49/月）**：多机节点混合编排、共享协作空间与团队经验库、托管连接器与合规权限审计。

### 关键北极星指标（不看虚荣指标）
1. **首次跑通率（Activation）**：安装后 10 分钟内成功接入 ≥2 个 Agent 并完成首次跨成员切换或任务交付的比例。
2. **核心价值指标（North Star）**：**每周由 DuolaWork 验收交付的有效成果数**（含人工在阅读器打开审阅/保存的文档、代码 Worktree 交付、以及连续运行 ≥3 期的定时任务）。
3. **真实留存指标（W2 Retention）**：第一周跑通交付的用户中，第二周主动回到同一项目继续推进或保留定时任务运行的比例。

## 7. 已确认拍板的 4 项核心决策（2026-11-27 锁稿）

1. **统一品牌与桌面包命名**：对外与桌面端统一命名为 **`DuolaWork`（`DuolaWork.app`，v3.0.0）**；桌面端内置兼容迁移，自动承接老用户既有 `userData` 与登录配置。
